## Recording audio

An `AudioRecorder` records from a microphone into memory:

```cpp
const AudioRecorder recorder;                       // the default input, 48 kHz mono

Button(Text([=] { return recorder.is_recording() ? "Stop" : "Record"; }), [=] { recorder.toggle(); });
ProgressView([=] { return recorder.level(); });     // a live input meter
Text([=] { return std::format("{:.1f} s", recorder.duration()); });
```

`start()` continues the recording, `stop()` pauses it, and `clear()` drops what was recorded. The
readers `is_recording()`, `duration()`, `level()` (the recent peak, 0 to 1) and `error()` are
reactive.

When you're done, take the recording out:

```cpp
recorder.save_wav("memo.wav");            // a 16-bit WAV file
std::vector<unsigned char> wav = recorder.wav();
std::vector<float> samples = recorder.samples(); // interleaved, -1...1
Sound memo = recorder.sound();            // to play it back
memo.play();
```

### Choosing an input

```cpp
for (const AudioDevice& device : audio_input_devices()) {
    // device.id, device.name, device.is_default
}

const AudioRecorder recorder({.device_id = chosen_id, .sample_rate = 44100, .channels = 2});
```

### Streaming

`on_samples` receives each block of samples as it arrives, for streaming or analysis. It runs on
the audio thread: keep it short, and don't touch views or state from it.

```cpp
const AudioRecorder recorder({.on_samples = [=](std::span<const float> block) { encoder->push(block); }});
```

## Camera

A `Camera` captures a camera's live picture, and `CameraView` shows it:

```cpp
const Camera camera;                             // the first camera, about 1280×720

CameraView(camera).frame(320, 180).clip_shape(RoundedRectangle(12));
Button(Text([=] { return camera.is_running() ? "Stop" : "Start"; }),
       [=] { camera.is_running() ? camera.stop() : camera.start(); });
```

`CameraView` fills its space by default, cropping the picture (`ContentMode::fit` shows all of
it). The preview is mirrored, as people expect to see themselves; set `.mirrored = false` in the
options to turn that off.

`is_running()`, `size()` (the frame size in pixels) and `error()` are reactive.

### Snapshots

`snapshot()` returns the newest frame as a PNG image, not mirrored, or `nullopt` before the first
frame:

```cpp
if (auto png = camera.snapshot()) {
    std::ofstream("snapshot.png", std::ios::binary).write(reinterpret_cast<const char*>(png->data()), png->size());
    // or show it: Image({.data = *png})
}
```

### Choosing a camera

```cpp
for (const CameraDevice& device : camera_devices()) { /* device.id, device.name */ }

const Camera camera({.device_id = chosen_id, .width = 1920, .height = 1080});
```

The camera's closest mode to the requested size is used. Virtual cameras, such as OBS's, work too.

### How frames get to the screen

Camera frames stay in the camera's own format (usually NV12 or YUY2) and are converted to RGB on
the GPU. Views showing a camera redraw on their own as frames arrive, without involving the UI
thread.
