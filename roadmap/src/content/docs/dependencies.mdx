Each spec page lists the specs it builds on. This page is generated from those lists. If a spec
names a dependency that doesn't exist, or the dependencies form a cycle, the site fails to build.

A dependency means "you need this working first". It does not mean "you need all of it". Where
only one piece of an earlier part is needed, the spec says which piece.
