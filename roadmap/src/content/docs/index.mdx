This site breaks Elegance into everything you need to write yourself: the design decisions, the
subsystems, the order to build them in, and the traps the current code already fell into. Every
topic has a spec explaining how it works and a checklist you tick off as you build it.

<Overview />

## Two kinds of page

In the sidebar, each part lists its topics. A topic's title opens its **spec**, and the
**↳ Checklist** entry under it opens its checklist. They also link to each other from their titles.
The **Concepts** section explains ideas that cut across parts: [lowering](how/concepts/lowering/),
[a frame from start to finish](how/concepts/frame/), and
[redrawing only what changed](how/concepts/redraw/).

- **Specs** explain how the part should work: what it's for, the model and algorithms, the rules
  it must keep, and its edge cases. Each lists what it **depends on** and what's **needed by** it.
  The [Dependency map](dependencies/) collects these into build waves.
- **Checklists** turn the spec into tasks you tick off.

Read the spec, then work through the checklist.

## How each checklist works

- **Depends on**: what has to exist first.
- **Read first**: the `design.md` sections and the files in this repo that do it today. Treat them
  as a reference to check your work against, not something to copy.
- **Tasks**: what to build, in a sensible order.
- **Done when**: how to prove it works before moving on.
- **Gotchas**: problems the existing code already hit, so you don't have to rediscover them.

The parts are in dependency order. Inside a part, pages are in order too. A page from a later
part sometimes needs only one item from an earlier one; the page says so. Start with
[Lessons learned](lessons/) for a skim of every trap at once.

:::tip[Keeping your progress]
Ticks are saved in this browser's local storage, so they survive closing the tab but not clearing
site data or changing browsers. Use **Export progress** above now and then to keep a backup, and
**Import progress** to restore one. **Hide done** on each page hides the items you've ticked.
:::
